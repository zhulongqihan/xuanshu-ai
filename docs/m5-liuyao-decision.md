# M5 六爻首版规则决策

状态：首版规则引擎、案例存储与 Web 工作区已完成；人工复核集待补
更新日期：2026-08-21

## 目标

首版六爻先交付可复算、可审计的问事盘面，不把流派解释直接写成确定性事实。用户可以使用三枚硬币、手工爻值或已有六爻值生成同一套结构化盘面，并在后续由 Agent 基于盘面和证据进行解释。

## 固定规则

- 爻值严格使用 6、7、8、9，爻序严格从初爻到上爻（自下而上）。三枚硬币分别记录 2 或 3，三次相加得到爻值；18 个原始值必须能复算六爻，篡改后的组合拒绝保存。
- 本卦使用阴阳位编码，初爻为最低位；6、9 为动爻，动爻翻转后生成变卦。
- 纳甲采用《火珠林》常用八卦纳干纳支表，并为每一爻输出天干、地支和地支五行。
- 六十四卦使用固定卦名表；八宫、卦宫五行和本宫/一世至五世/游魂/归魂位置固定记录在结果中。
- 六亲以卦宫五行为“我”，按照同我、我生、生我、我克、克我映射为兄弟、子孙、父母、妻财、官鬼。
- 六神按日干安起，从初爻顺排；旬空由六十甲子日序的旬组推导。
- 世应按八宫序列定位，月建取起卦当地时刻对应的节气月支；农历日期和干支日同时保存为时间上下文。

## 明确不纳入首版

- 不输出用神旺衰、伏神、飞神、冲合刑害的断语，不把“某爻代表某现实事件”自动判定为事实。
- 尚未支持真太阳时换日、子初换日的流派选项、不同纳甲表、不同世应表、六爻古籍案例自动判读。
- 月建、日辰和旬空只作为结构化上下文，AI 解读必须引用对应规则和输入，不得绕过盘面生成结论。
