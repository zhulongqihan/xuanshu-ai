# M6 综合 Agent 首版路由决策

状态：active
更新日期：2026-08-21

## 路由边界

- 先由 `packages/agent/src/router.ts` 对问题做确定性术语匹配，再决定使用八字、紫微、黄历、六爻或综合入口。
- 命中多个系统，或用户明确要求“综合/结合/比较”，必须进入 synthesis；不能让单一术数冒充全部事实。
- 没有命中特定术语时保留综合入口，但只附带最小事实范围，并要求解释层披露资料不足。
- 路由输出保存版本、命中的术语、原因和安全等级，后续模型只能解释路由后提供的结构化 facts。

## 高风险边界

健康、死亡、犯罪、法律、投资、借贷等词命中后标为 `high_risk`，模型提示必须要求克制表达、明确不替代专业意见，不得以恐惧或确定性结论诱导用户行动。
