# M4 紫微斗数首版决策

状态：规则引擎首版已实现，Web 快照与页面仍在接入
更新日期：2026-08-21

## 首版边界

- 使用 `iztro@2.5.8` 作为固定版本的三合基础排盘适配器。
- 输入来自已经归一化并带哈希的出生记录，农历日期沿用本项目 HKO 解析结果。
- 固定记录立春分界、当前日界、普通虚岁起限和默认安星算法；配置写入结果，避免库默认值漂移。
- 输出十二宫、命宫/身宫、五行局、主辅杂曜、亮度/四化字段和大限区间。
- 民用时间是紫微首版输入；八字的真太阳时只作为八字候选，不静默替换紫微盘。
- 精确时刻生成完整候选；约略时间生成中心时刻的 `partial` 候选；未知或不存在时刻不伪造盘面。

## 证据与不确定性

排盘事实与后续解释分层。星曜位置、大限区间属于排盘适配器输出；格局、吉凶、性格和事件判断不在本引擎内生成，必须由后续解释层引用对应规则。闰月、早晚子时和真太阳时差异都不能被隐藏在一个“确定盘”里。

## 后续接入

1. 将紫微计算结果与人物档案 revision 绑定成独立快照，不与八字 payload 混合。
2. 页面展示十二宫和大限，保留候选与配置说明。
3. 增加至少 100 个人工/参考盘黄金案例后，再开启紫微解释性规则。
