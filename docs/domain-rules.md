# 术数规则与流派边界

状态：已采纳
更新日期：2026-07-22

## 1. 历法基座

首个正式支持区间为 1901-2100，与香港天文台公农历对照资料的覆盖范围一致。
范围外输入必须标记为实验结果，未建立独立验算前不得宣称同等精度。

出生输入同时保存：

- 用户录入的原始日期、时间和历法类型。
- 地点名称、经纬度、IANA 时区和当时的 UTC 偏移。
- 标准民用时间、UTC 时间和计算得到的真太阳时。
- 与节气、23:00、00:00 和时辰边界的距离。
- 用户提供的时间不确定范围。

真太阳时不得静默覆盖原始民用时间。边界差异会改变盘面时，应用必须并列生成候选结果，
只输出在候选盘之间稳定的结论，或明确说明差异。

## 2. 八字默认规则集

规则集 ID：`bazi-ziping-v1`

- 以立春作为干支年的默认边界。
- 以十二节作为月柱边界，不以农历初一换月。
- 默认以当地民用日期 00:00 换日。
- 子时为 23:00-00:59；同时提供子初换日规则作为显式对照选项。
- 默认盘使用民用时间，真太阳时盘作为可见对照，不在后台自动替换。
- 四柱、藏干、十神、纳音和十二长生属于确定性输出。
- 旺衰、格局、调候、扶抑和用神属于规则推断，不得伪装成唯一客观答案。
- 大运顺逆和起运算法必须记录规则版本，并用节气精确时刻而非固定天数估算。
- `bazi-ziping-v1` 的日干支以 GB/T 33661-2017 第 6.3.2 条所列
  `1949-10-01 = 甲子日` 为锚点，按当地所选时间基准的民用日期连续递推。
- 默认起运换算采用连续时差的“三日折一年”：4320 分钟折一年、360 分钟折一月、
  12 分钟折一日、1 分钟折二小时；结果同时保存原始秒数，展示值不得反推覆盖原值。
- 藏干首版采用单独版本化的现代通行本气/中气/余气表。它与古籍“人元司事”的逐日
  旺用分配并非同一数据，不得把两者的名称、顺序或权重互换。

首版解释以子平体系为主。《渊海子平》《三命通会》《滴天髓》和《子平真诠》
之间存在差异时，规则分别记录，不拼接成无来源的新规则。

## 3. 老黄历默认规则集

规则集 ID：`almanac-xiejibianfang-v1`

- 计算农历、干支、节气、建除十二神、值神、二十八宿、冲煞、方位和日时宜忌。
- 通用宜忌以《钦定协纪辨方书》可追溯规则为主，开源库只负责候选计算。
- 择日必须先选择具体事项，例如出行、搬迁、签约或祭祀，禁止脱离事项泛化吉凶。
- 个性化择日先应用通用禁忌，再检查与用户八字的冲合刑害，并分别展示两层依据。
- 不输出缺乏规则解释的单一“吉利指数”。日期比较使用“适合、谨慎、冲突、资料不足”。

## 4. 紫微斗数默认规则集

规则集 ID：`ziwei-sanhe-v1`

- 使用三合体系作为首版解释基线。
- 以固定版本 `iztro` 生成十二宫、命身宫、五行局、星曜、四化和运限候选数据。
- 四化表、星曜亮度和安星差异必须在配置中版本化并可展示。
- 首版支持本命、大限、小限、流年、流月、流日和流时的结构化盘面。
- 飞星、钦天等流派以后以独立规则集加入，不混入 `ziwei-sanhe-v1`。
- 闰月、早晚子时和排盘性别会影响结果时必须提示并支持候选盘比较。

## 5. 六爻默认规则集

规则集 ID：`liuyao-wenwanggua-v1`

- 采用文王卦、纳甲体系，以《增删卜易》《卜筮正宗》和《火珠林》为主要来源。
- 支持三枚铜钱、手工录入六爻和录入已有本卦/动爻三种方式。
- 六爻顺序固定为由初爻到上爻，接口和界面都必须明确展示方向。
- 程序起卦使用密码学安全随机数，保存每次抛掷值和算法版本；AI 不得选择或重掷。
- 确定性输出包括本卦、变卦、宫位、世应、纳甲、六亲、六神、旬空和月建日辰。
- 用神、旺衰、动变、冲合生克和应期属于版本化规则推断，必须与具体问题类别绑定。
- 没有明确问题或缺失原始爻值时，不生成伪造的六爻判断。

## 6. 规则文件契约

每条机器可执行规则必须包含：

```yaml
id: bazi.example.rule
system: bazi
ruleset: bazi-ziping-v1
version: 1.0.0
status: active
inputs: []
output: {}
source_refs: []
certainty: rule_based
notes: ""
```

规则 ID 发布后不可复用。修改输入、计算或含义时升级语义版本；只修正文案可升级补丁版本。
任何规则集升级都必须保留旧命盘的复算能力，命盘快照不得被后台批量改写。
