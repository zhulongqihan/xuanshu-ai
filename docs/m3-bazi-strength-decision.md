# M3 八字旺衰基础量决策

状态：已采用

更新日期：2026-08-21

## 目标

先交付可复核的旺衰基础量，不把五行统计直接包装成绝对吉凶或高风险人生判断。

## 当前规则

1. 日主取日柱天干；月令取月柱地支元素，并输出二者关系：同类、资源、泄、财或官。
2. 四柱每个透干计 1.0 分；藏干按人元角色计分：本气 0.7、中气 0.4、余气 0.2。
   五行分布同时保留透干数量、藏干数量和加权分数，用户可以复算总和。
3. 支中藏有与日主同元素的地支记为“有根”，不以单一根气直接推出吉凶。
4. 支持元素为日主同元素与生助日主的资源元素。支持比例为：
   `支持分 ÷（支持分 + 其他元素分）`。比例 `>= 0.6` 标记为 `supportive`，
   `<= 0.4` 标记为 `less_supported`，其余为 `balanced`；这是透明的工程分级，不是科学结论。
5. 缺少时柱时仍可计算现有三柱，但候选和总结果都标记为 `partial`，不补造时柱。

## 边界

- 当前只输出基础量、关系和初步分级，不生成健康、死亡、犯罪、投资或法律判断。
- 没有把流派差异压成一条“唯一旺衰规则”；后续若引入调候、格局、从格等规则，必须新增规则集、
  来源定位和黄金案例，不覆盖本基础量。
- AI 只可以解释这些结构化字段，不能修改或反推事实层数值。
